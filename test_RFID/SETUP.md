# วิธีติดตั้งและรัน rfid_reader.py (บน Windows)

## 1. เช็คว่ามี Python ติดตั้งอยู่หรือยัง

เปิด **Command Prompt** หรือ **PowerShell** แล้วพิมพ์:

```
python --version
```

ถ้าขึ้นเวอร์ชัน เช่น `Python 3.11.x` แปลว่าใช้ได้เลย
ถ้าไม่มี ให้ไปโหลดที่ https://www.python.org/downloads/ แล้วติดตั้ง (ตอนติดตั้งอย่าลืมติ๊ก **"Add python.exe to PATH"** ด้วย)

---

## 2. ติดตั้งไลบรารีที่ต้องใช้

เปิด Command Prompt ที่ตำแหน่งโฟลเดอร์ที่มีไฟล์ `rfid_reader.py` แล้วรันคำสั่ง:

```
pip install hidapi
```

ไลบรารีนี้ใช้เชื่อมต่ออุปกรณ์ USB HID โดยตรง (คือส่วนที่ทำให้เราแยกเครื่องอ่าน RFID ออกจากคีย์บอร์ดจริงได้)

**ถ้า pip install แล้วขึ้น error เกี่ยวกับ build/compiler:**
ให้ลองใช้ตัวสำเร็จรูปแทน:
```
pip install hid
```
หรือถ้ายังไม่ได้ ให้ลองอัปเดต pip ก่อน:
```
python -m pip install --upgrade pip
pip install hidapi
```

---

## 3. รันโปรแกรม

ในโฟลเดอร์เดียวกับไฟล์ `rfid_reader.py` รันคำสั่ง:

```
python rfid_reader.py
```

โปรแกรมจะ:
1. แสดงรายการอุปกรณ์ USB HID ทั้งหมดที่เสียบอยู่ในเครื่อง (รวมคีย์บอร์ดจริงด้วย)
2. ให้เลือกหมายเลขของอุปกรณ์ที่เป็นเครื่องอ่าน RFID (ดูจากชื่อ/hint ที่โปรแกรมช่วยไฮไลต์ให้)
3. จำอุปกรณ์ที่เลือกไว้ ครั้งต่อไปไม่ต้องเลือกใหม่
4. รอรับการแตะบัตร แล้วพิมพ์ผลลัพธ์ตัวเลขออกมาให้ดู

กด **Ctrl+C** เพื่อหยุดโปรแกรม

---

## เทคนิคช่วยหาว่าอุปกรณ์ไหนคือเครื่องอ่าน RFID

ถ้าไม่แน่ใจว่าตัวไหนในลิสต์คือ R80CP:

1. **ถอดเครื่องอ่าน RFID ออกก่อน** รันโปรแกรม จดจำนวน/รายชื่ออุปกรณ์ที่ขึ้น
2. **เสียบเครื่องอ่านกลับเข้าไป** รันโปรแกรมอีกครั้ง เทียบดูว่ารายการไหนที่โผล่มาใหม่ — ตัวนั้นแหละคือ R80CP
3. หรือเปิด **Device Manager** (พิมพ์ในช่องค้นหา Windows) → ขยาย **Keyboards** หรือ **Human Interface Devices** → ดูชื่ออุปกรณ์ที่เพิ่งเสียบเข้าไปตรงกับที่โปรแกรมแสดง

## ปัญหาที่อาจเจอ

| อาการ | วิธีแก้ |
|---|---|
| `เปิดอุปกรณ์ไม่ได้` / Permission error | ลองคลิกขวาที่ Command Prompt เลือก **Run as administrator** แล้วรันใหม่ |
| ไม่มีอุปกรณ์ขึ้นในลิสต์เลย | เช็คว่าเสียบสาย USB แน่นหรือยัง / ลองสลับพอร์ต USB |
| แตะบัตรแล้วไม่มีอะไรขึ้น | ลองแตะบัตรให้นานขึ้นเล็กน้อย / เช็คว่าเลือกอุปกรณ์ถูกตัวหรือไม่ (ลองลบไฟล์ `rfid_device.json` แล้วเลือกใหม่) |
| ตัวเลขที่ได้ไม่ตรงกับที่คาดไว้ | เครื่องอ่านอาจถูกตั้งค่ารูปแบบเอาต์พุตไว้ต่างจากที่คาด ลองใช้ซอฟต์แวร์คอนฟิกของผู้ผลิตปรับรูปแบบใหม่ |

---

## ไฟล์ที่เกี่ยวข้อง

- `rfid_reader.py` — สคริปต์หลัก
- `rfid_device.json` — ไฟล์ที่โปรแกรมสร้างขึ้นอัตโนมัติ เพื่อจำอุปกรณ์ที่เคยเลือกไว้ (ลบทิ้งได้ถ้าอยากเลือกอุปกรณ์ใหม่)
